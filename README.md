# StashScrubber（iOS 版）

Stash 媒体库的 **iOS 客户端（Flutter）**，兼容 **Stash 0.31.x**。

> 原 SwiftUI 原生 iOS 版（v1.6.0）已归档备份到分支 `backup/native-ios-1.6.0`。

## 功能总览

### 短片
- 双排横版卡片：封面、时长、分辨率、收藏星标、字幕角标（检测到外挂字幕显示「字幕」）
- 无限滚动加载，返回保持进入位置，无翻页按钮
- 合并搜索：标题 / 路径 / 详情 + 演员名 + 标签 + 工作室
- 排序（时间从新到旧等）+ 筛选（工作室/演员/标签带搜索、多选）+ 多选批量（收藏/评分/标签/合并/封面/设置工作室/添加演员/全选），批量里的工作室/演员/标签选择弹窗均带搜索框
- 详情页：削刮（保留已有工作室，标签与本地已有标签取并集不覆盖）、编辑、收藏、合并、生成封面、文件路径复制、相关演员/工作室跳转
- 收藏页三子页：短片（已整理）/ 演员（星标）/ 工作室（星标）

### 演员
- 网格卡片 + 无限滚动 + 搜索；详情页含别名（默认显示 5 个、可查看更多）、合并、删除、星标收藏
- 详情页按「基本信息 / 身体数据 / 职业生涯 / 图像 / 社交 / 档案」分组折叠，收起态显示已填项数；年龄按出生（去世）日期推算
- 编辑与新建共用全字段折叠表单，保存只提交与原值的差异（清空的字段会真的清掉服务端值）
- 削刮（Stash-box / JavDB 等，默认保留原名）、手动新建

### 批量工具
- 批量识别：多刮削源（本地刮削器 / Stash-box）按优先级自动匹配短片元数据
- 去重：按感知哈希距离 + 时长差查找重复短片，多选合并
- 统计页：短片 / 图片 / 演员 / 工作室 / 标签等媒体库汇总指标
- 插件页：已安装插件列表、启停状态、任务 / 钩子数

### 工作室
- 网格卡片 + 无限滚动 + 搜索；详情页显示上级工作室 / 子工作室（可跳转）、星标收藏、删除
- 削刮、编辑、手动新建

### 标签
- 全部标签浏览 + 带标签的短片；详情页相关短片

### 服务器
- 多服务器档案（内网/外网，支持路径前缀）+ 工具栏一键切换 + 服务器相关设置二级菜单
- API Key 认证、连接测试、网络日志、诊断

### 扫描 / 任务
- 选择性文件夹扫描（短片+图片 Stash）、任务列表实时进度、清理任务

### 其他
- 主题三模式（跟随系统/浅色/深色）、生成封面、外挂字幕检测

## 构建

要求 macOS + Xcode 15+，详见 [BUILD_IOS_ZH.md](BUILD_IOS_ZH.md)。CI 使用 CodeMagic（`codemagic.yaml`），推送 `main` 自动编译 unsigned IPA。

## 服务器配置

1. 打开「设置」添加服务器档案：
   - 内网：`http://<NAS-IP>:9999`
   - 外网：`https://stash.example.com`（支持路径前缀，端点自动追加 `/graphql`）
2. 若 Stash 启用 API Key，填入对应档案。
3. 「测试连接」验证后，各列表页可一键切换内外网档案。
